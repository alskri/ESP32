# FNIRSI SWM-10: русификация прошивки V1.4

`APP_SWM-10_V1.4_RU.bin` — прошивка точечной сварки FNIRSI SWM-10 V1.4 с русским интерфейсом.
Русский занимает место английского (в меню языка пункт «Русский»), китайский язык не тронут.
`preview_before_after.png` — сравнение подписей «было/стало».

## Что изменено
- Дописаны кириллические глифы в шрифты 6x12 и 8x16 (кодировка CP1251).
- В обработчик строк добавлена небольшая заплатка: в не-китайском режиме байты >= 0x80 рисуются как буквы.
- Английские строки заменены русскими на месте, пересчитаны ширины для бегущей строки.

## Предупреждение
Проверено только в эмуляторе (отрисовка строк кодом прошивки). На реальном устройстве не тестировалось.
Неизвестно, проверяет ли загрузчик контрольную сумму или размер файла. Сохраните оригинальную прошивку для отката. Шьёте на свой риск.
