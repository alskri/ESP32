# FNIRSI SWM-10: русификация прошивки V1.4

`APP_SWM-10_V1.4_RU.bin` — прошивка точечной сварки FNIRSI SWM-10 V1.4 с русским интерфейсом.
В меню выбора языка теперь два языка: **Русский** (вместо китайского) и **English** (оригинальный, без изменений).
`preview_before_after.png` — сравнение подписей English / Русский.

## Что изменено
- Дописаны кириллические глифы в шрифты 6x12 и 8x16 (кодировка CP1251).
- В русском режиме прошивка идёт по «английской» ветке (те же раскладки экранов и бегущие строки), а перед выводом
  английская строка подменяется русской. Ширина бегущей строки пересчитывается на лету.
- Пункт китайского языка в меню заменён на «Ру»/«Русский». Язык переключается между English и Русский.
- Все английские строки в прошивке остались байт-в-байт как в оригинале (изменено 40 байт кода плюс дописанные данные).
- Старая настройка «китайский» из флеша при загрузке трактуется как русский.

## Предупреждение
Проверено только в эмуляторе (отрисовка строк кодом прошивки, логика переключения языка). На реальном устройстве не тестировалось.
Неизвестно, проверяет ли загрузчик контрольную сумму или размер файла. Сохраните оригинальную прошивку для отката. Шьёте на свой риск.
